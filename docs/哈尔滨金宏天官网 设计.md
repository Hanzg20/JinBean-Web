## **一、 项目背景与设计目标**

### **1.1 项目背景**

哈尔滨金宏天科技开发有限公司作为传统的公用事业（供暖、供电、供气等）软件及系统提供商，正处于向“新一代 AI 智能体 \+ 智慧支付与物联（IoT）解决方案集成商”全面转型的战略交汇点。公司拥有深厚的 POS 硬件协议适配、聚合支付网关集成与底层软硬件交互能力，并与海外公司展开技术与业务跨国协同。本次网站重构旨在重塑品牌数字化形象，准确传递“底座深厚、AI 创新、国际协同”的企业实力。

### **1.2 核心设计目标**

* **形象转型**：从“传统小软件外包/单体应用服务商”升级为“AI+智慧支付与公用事业物联全栈解决方案商”。  
* **B端对接**：精准吸引支付网关公司、POS 硬件厂商、自助终端制造商及公用事业/工程企业等目标客群。  
* **视觉与品牌统一**：沿用 \[www.jinbean.com\](https://www.jinbean.com) 与 www.GoldSky.ca 的视觉基因与配色体系，确保国内与海外品牌的相互呼应。  
* **搜索与主体一致性**：确保网站呈现的企业信息与百度、Google 搜索引擎抓取的实体工商与备案信息高度匹配，提升权威性与信任度。

## **二、 品牌定位与标语体系**

### **2.1 品牌定位 (Brand Positioning)**

**具备深厚支付与 POS 底蕴的 AI+公用事业与智慧物联（IoT）解决方案服务商。**

### **2.2 核心竞争优势 (Core Value Propositions)**

1. **精通支付底座**：深刻理解软硬件交互协议，支持各类 POS 机、智能卡/NFC、银联及在线网关的无缝打通。  
2. **垂直行业深耕**：水电气暖预付/后付费系统、房屋维修资金监管系统、5G+智慧工地一体化管理。  
3. **前沿 AI 转型**：融入智能客服机器人、AI 视觉购物/缴费终端、伴学智能体（EdTech AI Agent）。  
4. **跨国技术联动**：与加拿大 GoldSky 双平台协同，算法与场景深度融合。

### **2.3 品牌 Slogan 方案**

| 类型 | 中文 Slogan | 英文 Slogan (GoldSky 协同) |
| :---- | :---- | :---- |
| **主打标语** | 深度赋能支付，AI 重构场景 —— 链接软硬件生态的智能公用事业与物联专家 | Empower Payments, Reshape Scenarios with AI |
| **副标语** | 以支付为基，以 AI 为翼：软硬件一体化智能解决方案服务商 | Smart Hardware & Software Integrated AI Solutions |

## **五、 重点页面设计与内容规范**

### **5.1 首页 (Homepage) 布局设计**

1. **Header 导航区**：左侧为“金豆荚 JinBean”与“金宏天科技”双 Logo 组合；中间为导航菜单；右侧为“语言切换 (中/EN)”与“申请 API / 预约演示”高亮按钮。  
2. **Hero Banner 区域**：使用深海极光蓝背景，辅以动态数据流与 POS 设备网格动画。展示核心 Slogan，并提供“获取解决方案”与“体验线上 Demo”双入口。  
3. **支付底座能力展区**：突出呈现“精通 POS 交互协议 / 银联标准 / 支付宝与微信公用事业接口”，展示高并发与安全合规指标。  
4. **AI+产品矩阵区**：采用 3x2 网格卡片，展示水电气暖自助机系统、智能客服机器人、房屋维修资金系统、智慧工地与伴学智能体。

### **5.2 B端生态合作页面 (Ecosystem Partnership)**

| 目标合作伙伴 | 核心需求与痛点 | 金宏天提供的赋能方案 | 合作模式 |
| :---- | :---- | :---- | :---- |
| **POS 硬件厂商** | 硬件同质化，缺乏垂直行业应用场景软件 | 预装水电气暖缴费、维修资金线上刷卡等行业应用 | 软件预装 / 软硬件联合打包 |
| **自助机硬件厂商** | 缺乏复杂的支付接口对接能力与 AI 交互系统 | 提供全套自助购物/缴费 OS、嵌入式支付 SDK 与 AI 语音/视觉模块 | OEM 定制 / 系统授权 |
| **支付网关公司** | 需要拓展线下公用事业与智慧社区线下场景 | 负责线下终端部署、IC卡/NFC协议打通与行业系统对接 | 接口互通 / 场景联合共建 |
| **中小企业用户** | 希望快速、低成本部署智能化管理系统 | 提供云端模块化 SaaS 或轻量私有化部署 | 订阅制 / 按需集成 |
